# 처음 시작하기

[ispacecraft.com](https://ispacecraft.com)을 브라우저에서 열어 플레이합니다. 별도로 소스 코드를 내려받거나 개발 도구를 설치할 필요는 없습니다.

## 실행 환경

- WebGL과 Web Locks를 지원하는 브라우저가 필요합니다.
- 데스크톱은 키보드와 마우스, 터치 기기는 화면 스틱과 버튼으로 조작합니다.
- 같은 사이트에서 게임 탭은 하나만 실행합니다. 다른 탭에서 실행 중이라는 안내가 나오면 기존 탭을 닫아 주세요.
- 처음 접속하거나 업데이트한 뒤에는 초기 자료 준비에 시간이 걸릴 수 있습니다.

## 첫 플레이 순서

1. 시작 화면에서 새 게임 또는 캠페인을 선택합니다. 처음이라면 튜토리얼과 첫 항해 안내를 활용하세요.
2. 도움 기능을 선택합니다. 훈련생 프리셋은 보조 기능을 켜 주며, 각 기능은 나중에 설정에서 조정할 수 있습니다.
3. 선내 이동과 상호작용을 익히고 조종석에 앉습니다.
4. 가까운 목적지를 정해 비행하고, 채굴과 정거장 이용으로 자원을 확보해 봅니다.
5. 메뉴에서 저장을 확인하고, 중요한 진행은 파일로 내보냅니다.

화면에 표시되는 현재 목표와 행동 버튼을 따라가면 처음 필요한 조작을 익힐 수 있습니다. 키보드 조작이 헷갈리면 `?` 키 지도를 여세요.

## 캐릭터 선택

처음 실행할 때 얼굴 화면이 나오면 표준 얼굴로 시작하거나 사진으로 캐릭터를 만들 수 있습니다. 사진 입력은 필수가 아닙니다. 자세한 과정은 [캐릭터와 내 얼굴](guides/character.md)을 참고하세요.

## 도움 기능

| 기능 | 도움을 주는 부분 |
|---|---|
| 보조 비행 | 조종 중 이동 키를 놓으면 멈추도록 지원 |
| 자동 관리 | 헬멧·안전줄·일부 자원 관리를 보조 |
| 계기판 숨기기 | 조종 화면을 단순하게 표시 |
| 매직 버튼 AI 추천 | 상황에 필요한 행동 버튼을 추천 |

도움 기능은 설정에서 개별적으로 바꿀 수 있습니다. 산소·연료 등 생존 자원은 계속 확인해야 합니다.

## 화면에서 확인할 것

- **상태창**: 산소·몸·연료와 현재 알림.
- **네비게이션**: 목적지, 비행 정보와 지도.
- **AI 패드**: 현재 상황과 관련 앱·정보.
- **아래 행동 버튼**: 지금 가능한 상호작용과 조종 동작.

프레임이 느리면 그래픽 품질을 낮추고 다른 무거운 탭을 닫아 보세요. 추가 도움은 [FAQ](faq.md)를 참고하세요.
