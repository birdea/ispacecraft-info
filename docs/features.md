# 기능 소개

개발 중인 ispacecraft에서 제공하는 기능을 소개합니다. 배포 시점에 따라 차이가 있을 수 있으며, 앞으로의 확장은 [공개 로드맵](roadmap.md)에서 따로 안내합니다.

## 이동과 우주선 조종

작은 우주선 안을 걷고 조종석에 앉아 비행합니다. 우주선 밖에서는 우주 유영을 하며 헬멧·안전줄·추진을 관리합니다. 관성 비행과 자세 제어, AI 항법, 궤도 이동과 자동 착륙을 지원합니다.

[우주선과 선내 이동](guides/spacecraft.md), [항법과 궤도 이동](guides/navigation.md)에서 장치 정리·상대 속도·출발과 도착 흐름을 설명합니다.

## 실제 태양계와 시간

태양계의 실제·가상 설정을 제공하고, 실제 모드에서는 공전·태양 중력·영향권 전환과 지원 항로의 궤도 전이를 다룹니다. 모든 모드가 같은 계산을 사용하지는 않습니다. [태양계와 시간](guides/solar-system.md), [물리와 축척](concepts/physics-and-scale.md)을 참고하세요.

## 행성 탐사

행성의 지형과 대기를 살펴보고 착륙 지점을 선택합니다. 산·강·바다·생물대 등 표면 표현과 지형 지도를 제공하며, 경사와 물·대기 조건이 접근과 착륙에 영향을 줍니다.

현재 행성 표현은 개발 중이며, 실사에 가까운 태양계 외관은 후속 개선 계획입니다.

지구에는 식생과 여러 동물의 표현도 있습니다. 실제 지리와 생태계 전체를 재현하는 기능과는 구분합니다. [착륙과 지표 탐사](guides/planet-exploration.md)에 자세히 설명했습니다.

## 생존과 자원

산소·연료·식량·물과 몸 상태를 관리합니다. 광석과 물을 채굴하고, 자원을 활용해 항해를 이어 갑니다. 도움 기능을 켜면 일부 비행과 자원 관리를 보조받을 수 있습니다.

떠 있는 광석과 운석 착륙 채굴·행성 매장지는 접근과 작업 방식이 다릅니다. [생존](guides/survival.md), [채굴과 자원 변환](guides/mining.md)을 참고하세요.

## 정거장

정거장에 도킹해 거래·정비·업그레이드를 이용합니다. 도킹한 뒤 대상 정보나 현지 안내에서 이용할 서비스를 확인하세요.

공유 창고를 통해 같은 기기의 세계·캠페인 사이에서 자원과 장비를 보관할 수 있습니다. [정거장과 공유 창고](guides/stations-and-vault.md)에 보존 범위와 제한을 정리했습니다.

## 화면과 소리

조종 계기판, 네비게이션, AI 패드와 상황별 행동 버튼을 사용합니다. 패널을 접거나 위치를 조정하고, 그래픽 품질·조작·도움 기능을 설정할 수 있습니다. 자체 음악과 효과음, 기기의 음악·영상 재생을 지원합니다.

별도 화면 보호기로 태양계 항해 장면도 감상할 수 있습니다. [화면과 도움 기능](guides/interface.md), [음악과 미디어](guides/audio-and-media.md)를 참고하세요.

## 캐릭터와 내 얼굴

우주복·체형·얼굴과 꾸미기를 조절합니다. 카메라나 사진 파일에서 읽은 얼굴 특징으로 카툰 얼굴을 만들 수 있으며 표준 얼굴도 사용할 수 있습니다. 사진은 기기 안에서 처리하고, 협동 중 얼굴 모양 공유는 별도로 선택합니다. [캐릭터와 내 얼굴](guides/character.md)을 참고하세요.

## P2P 협동

방 코드와 방장 승인을 통해 다른 플레이어와 같은 방에서 플레이합니다. 서버가 항상 세계를 유지하는 지속 온라인 우주와는 구분됩니다. 참가 가능한 모드와 방 상태는 실행 중인 앱의 안내를 확인하세요.

[같이 하기](guides/co-op.md)에서 현재 동기화와 개인 세계·공유 창고의 제한을 설명합니다.

## 저장

자동 저장, 수동 저장 칸, 저장 파일 내보내기·가져오기를 지원합니다. 데이터는 현재 기기·브라우저에 보관하며 기기 간 자동 동기화는 제공하지 않습니다.
