# 물리와 축척을 읽는 방법

ispacecraft는 관성·중력·궤도·대기·압력 같은 개념을 플레이에 활용합니다. 실제 자료를 참고하는 부분, 계산을 단순화한 부분, 플레이를 위한 별도 규칙이 함께 있습니다.

## 실제 자료와 근사

| 영역 | 읽을 때 구분할 것 |
|---|---|
| 천체 | 실존 천체의 이름·크기·중력·궤도 특성을 참고하지만 모든 관측 자료를 정밀 복원하지는 않습니다. |
| 궤도 | 해석식·수치 계산과 영향권 모델을 사용합니다. 모든 천체의 중력을 동시에 푸는 전 우주 다체 시뮬레이션은 아닙니다. |
| 대기 | 저항·가열·흔들림·압력·온도를 플레이 규칙으로 근사합니다. |
| 지형 | 착륙·채굴에 연결되는 지형과 시각적 표면 꾸미기를 구분합니다. |
| 추진 | 실제 조종 상태와 연결된 분사·가속을 표현하지만 모든 엔진의 열유체 계산을 수행하지는 않습니다. |
| 자원 변환 | 태양 광석 등 세계관의 허구와 게임 규칙을 포함합니다. |

## 거리와 속도

실제 우주 모드와 거리 압축을 사용하는 가상 우주 모드는 규모와 이동 시간이 다릅니다. 실사에 가까운 외관은 시각적 목표이고, 거리 축척은 플레이 조건입니다.

표시된 속도가 어떤 천체에 대한 상대 속도인지도 확인해야 합니다. 지구와 함께 이동하는 상태와 태양 기준으로 정지한 상태는 같은 뜻이 아닙니다.

## 시간 배속과 목표 속도

시간 배속은 세계가 진행되는 속도에, 목표 속도는 우주선의 항행 조건에 관계됩니다. 시간 가속 중에는 자원·위험·접근 단계도 함께 살펴야 합니다. UI가 제공하는 배속 한도와 자동 감속을 따르세요.

브라우저를 떠난 동안의 동면 계산도 실행 중인 세계를 모든 세부까지 그대로 재생하는 것은 아닙니다.

## 별도 플레이 규칙

이착륙 준비 비용과 사고 판정, 도움 기능, 장비 단계·가격은 플레이의 선택과 난이도를 위한 규칙입니다. 화면에 나오는 연료량이나 손상 수치를 실제 우주선 설계·항법 데이터로 해석하지 마세요.

교육용 수업 모드·교사용 도구·전문 계산 서비스는 현재 제공 기능으로 확정하지 않았습니다.
