# 캠페인 안내

현재 제공되는 모드와 캠페인을 간단히 소개합니다. 새로운 캠페인 구상은 [공개 로드맵](roadmap.md)에서 확인할 수 있습니다.

| 모드·캠페인 | 내용 |
|---|---|
| 튜토리얼·첫 항해 안내 | 선내 이동·조종·채굴·자원 사용·정거장 이용을 익힙니다. |
| 랜덤 성계 | 생성된 성계에서 탐사·채굴·생존을 이어 갑니다. |
| 태양계 | 태양계 천체를 배경으로 항해합니다. 시작 설정에서 실제·가상 공간과 속도 조건을 고릅니다. |
| 함대전 탈출 | 전장에 휘말린 우주선으로 위험을 피해 탈출합니다. |
| 고물상 | 전장 잔해에서 자원을 확보하고 살아 돌아옵니다. 더 수집할지 귀환할지 판단해야 합니다. |
| 구조선 | 공기가 남아 있는 탈출 캡슐의 조종사를 구조하고 귀환합니다. 구조 순서와 수용 인원을 고려합니다. |

## 함대전에서 고르는 것

### 휘말린 화물선

전장을 이기는 전투기가 아니라 전장에서 빠져나와야 하는 우주선의 입장입니다. 남은 화물·선체 상태와 탈출 경로를 보고 살아 나오는 판단이 중심입니다.

### 고물상

작은 잔해와 값진 수거 대상을 오가며 얼마나 확보할지 결정합니다. 수집한 짐과 작업에 드는 시간·위험이 늘어나므로 더 들어갈지 귀환할지 골라야 합니다.

현재 캠페인의 잔해 수거는 모든 플레이어의 옛 우주선을 보존·해체하는 장기 시스템과는 다릅니다.

### 구조선

캡슐마다 남은 공기가 다르고 우주선에 태울 수 있는 인원에도 한도가 있습니다. 가까운 대상을 먼저 건질지, 곧 위험해질 대상을 먼저 향할지 판단합니다. 구조한 인원이 늘면 선내 자원 관리도 중요해집니다.

### 결과와 공유 창고

성공적으로 귀환하면 캠페인별 조건에 따라 보상을 정산합니다. 실패 시 보존 범위와 창고 용량을 확인하세요. 성공 기록과 장비·자원을 다른 항해에서 활용하는 흐름은 [정거장과 공유 창고](guides/stations-and-vault.md)에 설명했습니다.

## 플레이 전에

- 태양계의 실제·가상 설정은 거리와 이동 조건에 영향을 줍니다. 처음에는 목적지까지 걸리는 시간과 현재 속도를 확인하세요.
- 캠페인마다 시작 조건·목표·종료 방식과 보상이 다릅니다. 입장 안내와 결과 화면을 기준으로 확인하세요.
- 함대전 판은 중간 상태를 저장하지 않으며 종료할 때 기록과 보상을 정산합니다.
- 캠페인과 협동의 조합에는 제한이 있습니다. 함께 플레이할 때는 참가 화면의 안내를 확인하세요.

## 계획 중인 캠페인

[지구 궤도 위성 캠페인](campaigns/earth-orbit.md)은 개발 예정입니다. 약 1만 6천 개 규모의 인공위성을 표현하고 개별 위성을 찾아 관측·추적하는 방향을 검토하고 있습니다. 현재 플레이 가능한 캠페인 목록에는 포함되지 않습니다.
