# 저장과 데이터

진행·설정과 캠페인 기록은 현재 기기와 브라우저에 보관합니다. 다른 브라우저나 기기로 자동 동기화되지 않습니다.

## 저장 범위

| 항목 | 안내 |
|---|---|
| 자동 저장 | 현재 세계의 진행을 보관합니다. |
| 수동 저장 | 메뉴에서 별도 저장 칸에 세계를 보관합니다. 가능한 모드에서 사용하세요. |
| 내보내기·가져오기 | 세계 저장본을 파일로 보관하거나 다시 읽습니다. |
| 공유 창고·캠페인 기록 | 세계 저장본과 별도로 브라우저에 보관합니다. 세계 내보내기 파일에는 포함되지 않습니다. |
| 함대전 판 | 진행 중인 판 자체는 저장하지 않고 종료 시 기록과 보상을 정산합니다. |

공유 창고라는 이름은 우주·캠페인 사이의 자원 이동을 뜻합니다. 기기 간 클라우드 동기화를 뜻하지 않습니다.

## 진행을 보관하려면

1. 저장 가능한 모드에서 메뉴의 저장 기능을 확인합니다.
2. 중요한 시점의 세계는 수동 저장 칸에도 보관합니다.
3. 브라우저 데이터를 지우거나 기기를 바꾸기 전에 저장 파일을 내보냅니다.
4. 다른 기기에서는 앱의 가져오기 기능으로 세계 저장본을 읽습니다.

파일을 가져오거나 저장 칸을 불러올 때는 덮어쓰기 안내를 확인하세요. 공유 창고와 캠페인 기록은 세계 파일로 이동되지 않으므로, 세계 내보내기를 전체 데이터 백업으로 취급하지 마세요.

## 데이터가 보이지 않을 때

- 같은 기기·같은 브라우저·같은 브라우저 프로필에서 접속했는지 확인합니다.
- 시크릿 모드나 브라우저 데이터 삭제 이후에는 기존 저장이 남아 있지 않을 수 있습니다.
- 저장 공간 부족 등으로 저장이 실패했다면 앱의 알림을 확인합니다.
- 내보낸 파일이 있으면 가져오기를 시도합니다. 복구를 시도하기 전 남아 있는 저장 칸과 파일을 보관하세요.

## 같은 사이트는 한 탭에서

게임 탭은 한 번에 하나만 실행합니다. 다른 탭에서 실행 중이라는 메시지가 나오면 먼저 열었던 탭을 닫고 새로고침하세요.
