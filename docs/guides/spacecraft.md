# 우주선과 선내 이동

현재 우주선은 캡슐형 선실과 몸통 허브, 에어락·창고·엔진 구획을 중심으로 구성됩니다. 조종석의 비행과 사람이 직접 걷는 선내 생활이 이어집니다.

## 선내에서 하는 일

| 구획·장치 | 역할 |
|---|---|
| 조종석 | 착석 후 비행·항법·계기 확인 |
| 허브와 연결 통로 | 선실과 작업 구획 사이 이동 |
| 에어락 | 감압·가압을 거쳐 우주 유영과 귀환 |
| 창고 | 확보한 광석과 적재 상태 확인 |
| 엔진·채굴 장치 | 추진·자원 변환·채굴 관련 작업 |
| 태양판 | 빛을 받을 수 있는 상황에서 전력 확보 |

접근한 장치의 상호작용 안내를 확인하세요. AI 패드의 선내 바로가기도 이용할 수 있습니다. 앉기·일어나기·문 이동 같은 전환 동작에는 시간이 필요할 수 있습니다.

## 걷기와 떠다니기

중력이 있는 선내와 무중력·우주 유영 상태의 움직임은 다릅니다. 떠 있을 때는 입력을 놓았다고 바로 멈추지 않을 수 있습니다. 벽·물건과의 충돌과 몸 상태도 확인하세요.

중력 조절은 몸의 이동과 생활 조건에 연결됩니다. 외부 행성 환경과 우주선 내부 설정을 같은 값으로 생각하지 말고, 현재 표시된 상태를 기준으로 판단하세요.

## 에어락과 외부 작업

바깥으로 나갈 때는 우주복·헬멧·공기를 확인하고 문·압력 전환 절차를 따릅니다. 외부에서는 손잡기·안전줄과 추진을 활용합니다. 착륙한 곳에서는 사다리가 선내와 지표를 잇습니다.

전개 장치·서랍·문·사다리는 비행과 도킹의 조건에 연결됩니다. 자동 운항이 기다린다면 현재 접거나 정리해야 할 장치가 무엇인지 안내를 확인하세요. 밖에 사람이 있는 동안 가능한 동작에도 제한이 있습니다.

## 손상과 수리

선체 손상은 거친 착륙·충돌·대기 진입 과열 등으로 발생할 수 있습니다. 서랍이 끼거나 장비가 정리되지 않는 상황도 비행을 지연시킬 수 있습니다. 현장 수리·원격 수리·정거장 정비 중 가능한 경로를 확인하세요.

수리에 필요한 전력과 광석이 충분한지도 확인해야 합니다. 심한 손상이나 선체 파괴는 단순히 수리 버튼을 누르는 것만으로 해결되지 않습니다.

## 증축과 별도 착륙선

자유로운 모듈 증축, 별도 모선·착륙선 운용과 다양한 역할의 방은 [장기 구상](../concepts/future-society.md)에 포함됩니다. 현재 선내 구획과 장비 업그레이드를 해당 기능 전체의 완성으로 보지는 않습니다.
