# 캐릭터와 내 얼굴

우주복·체형·머리와 얼굴 꾸미기로 캐릭터 외형을 조정할 수 있습니다. 내 얼굴 기능은 사진을 그대로 입히는 방식이 아니라 얼굴의 형태를 카툰 캐릭터로 옮기는 방식입니다.

## 얼굴 만들기

설정의 캐릭터 항목에서 내 얼굴 만들기·편집을 엽니다. 시작할 때 얼굴을 등록하지 않았다면 얼굴 화면이 먼저 나올 수 있습니다. 사진을 쓰지 않고 표준 얼굴로 시작할 수도 있습니다.

| 입력 | 안내 |
|---|---|
| 카메라 | 기기의 카메라로 촬영하고 얼굴 모양을 읽습니다. |
| 사진 파일 | 정면 사진 한 장으로 생성할 수 있고 측면 사진은 선택적으로 추가합니다. |
| 표준 얼굴 | 사진 없이 기본 외형에서 꾸미기를 시작합니다. |

정면을 새로 고르면 기존 입력을 교체합니다. 측면 사진 추가를 취소하거나 인식하지 못해도 이미 만든 정면 얼굴을 유지할 수 있습니다.

## 꾸미기와 확인

얼굴 윤곽·턱·광대·눈매·두상과 색·캡·안경·수염·표정 등의 항목을 조절합니다. 미리보기를 돌려 정면·옆모습을 보고, 헬멧 안과 실제 화면 크기에서도 확인하세요.

사진에서 보이지 않는 두상이나 세부를 정밀하게 복원하는 기능은 아닙니다. 촬영 각도와 인식 결과에 따라 닮음이 달라질 수 있으며 사용자 보정과 스타일 조정으로 다듬습니다.

## 사진과 저장

사진은 브라우저 안에서 처리하고, 원본 사진을 저장하거나 서버로 보내지 않습니다. 기기에 남는 것은 얼굴 모양 정보와 꾸미기 값입니다. 설정에서 얼굴을 지울 수 있습니다.

## 같이 하기에서 보이기

내 얼굴 모양을 다른 참가자에게 보내는 설정은 기본적으로 꺼져 있습니다. 직접 켜면 같은 방 참가자에게 얼굴 모양과 꾸미기 값을 전달하며, 사진은 전송하지 않습니다.

공유를 끄더라도 닉네임과 우주복·체형 같은 일반 외모 정보는 협동 플레이에 사용됩니다. 자세한 안내는 앱의 개인정보 고지와 [데이터와 권한](../data-and-permissions.md)을 확인하세요.

프로필 카드와 우주선 외벽 초상 같은 활용은 현재 얼굴 생성 기능과 구분되는 후속 검토 항목입니다.
