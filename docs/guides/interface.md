# 화면과 도움 기능

화면은 상태 확인, 운항, 생활·작업, 즉시 행동을 나눠 보여 줍니다. 가운데 3D 장면을 보면서 필요한 정보를 열어 사용합니다.

## 주요 영역

| 영역 | 역할 |
|---|---|
| 상태창 | 산소·몸·연료, 현재 상태와 알림 확인 |
| 네비게이션 | 운항 정보·경로·목적지·지도·시간과 속도 제어 |
| AI 패드 | 생존 카드, 상황별 제안, 선내 바로가기, 우주인·가방·우주선·자원·미디어 등 |
| 아래 행동 버튼 | 현재 가능한 이동·상호작용·작업 동작 |
| 조종 계기판 | 자세·비행·궤도 등 조종 정보 |

패널을 접거나 숨기고 위치·크기를 조절할 수 있습니다. 좁은 화면에서는 배치와 표시 범위가 달라질 수 있습니다. 시간 배속과 목표 속도는 네비게이션의 해당 제어에서 확인합니다.

## AI 패드

생존 카드는 주요 상태와 남은 시간을 보여 줍니다. 상황별 제안은 가능한 대응 동작으로 연결되며, 선내 바로가기는 구획 사이 이동을 도와줍니다.

생존 카드 구성을 조정해도 위험한 자원은 위험 안내에 나타날 수 있습니다. 평소 요약 화면과 현재 위험을 알리는 화면의 목적이 다르기 때문입니다.

## 도움 기능 네 가지

| 기능 | 동작 |
|---|---|
| 보조 비행 | 조종 입력을 놓으면 역분사로 멈추도록 지원. 필요한 연료를 사용합니다. |
| 자동 관리 | 헬멧·안전줄과 일부 연료 변환·산소 생산을 보조합니다. |
| 계기판 숨기기 | 조종 화면과 관련 표시를 단순하게 만듭니다. |
| 매직 버튼 AI 추천 | 상황에 맞는 행동 버튼을 제안합니다. |

훈련생·조종사 프리셋은 이 스위치들의 조합입니다. 세계에 고정된 난이도 모드가 아니며 플레이 중에도 개별적으로 바꿀 수 있습니다. 생존 수치 자체를 모두 완화하는 설정으로 보지는 않습니다.

자동 관리가 어떤 스위치를 유지하고 있다면 해당 항목을 직접 바꿀 수 없는 이유가 표시될 수 있습니다. 직접 조절하려면 도움 설정과 해당 자원 제어를 함께 확인하세요.

## 매직 버튼

AI 추천을 끄면 설정에서 표시할 행동과 순서를 직접 고를 수 있습니다. 버튼이 보이는지뿐 아니라 현재 상황에서 사용할 수 있는 동작인지 확인하세요. 키보드에서는 현재 키 배치도 표시됩니다.
