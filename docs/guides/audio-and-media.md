# 음악과 미디어

자체 음악·효과음과 기기의 음악·영상 파일을 사용할 수 있습니다. 조종석에 앉아 있을 때뿐 아니라 AI 패드의 미디어 기능으로 제어합니다.

## 음악과 효과음

배경 음악은 우주 항해·작업·위험·귀환의 분위기를 위한 자체 곡으로 구성됩니다. 재생 목록과 재생·멈춤·곡 이동·음량 등의 제어를 제공합니다.

효과음은 추진·문·감압·장비·충돌·경고 등 현재 동작과 연결됩니다. 기기와 브라우저가 지원하면 진동도 일부 상황의 피드백에 사용됩니다. 진공과 선내·대기 환경에서의 소리 표현은 몰입을 위한 연출과 근사를 포함합니다.

## 기기의 음악과 영상

미디어 기능에서 지원하는 방식으로 파일이나 폴더를 선택합니다. 선택한 파일은 기기 안에서 읽으며, 폴더 접근 권한과 다음 접속 때의 복원 가능 여부는 브라우저 지원에 따라 달라질 수 있습니다.

로컬 폴더의 음악·영상은 서버로 업로드하지 않습니다. 브라우저에는 폴더 접근 정보와 재생 목록이 남을 수 있습니다. 다른 브라우저나 기기에 같은 파일이 자동으로 전달되지는 않습니다.

## 재생되지 않을 때

- 브라우저가 사용자 입력을 기다리는 경우 재생 버튼을 눌러 보세요.
- 배경 음악·효과음·미디어 음량과 음소거를 따로 확인합니다.
- 파일 형식과 브라우저의 재생 지원을 확인합니다.
- 폴더 권한이 만료되거나 파일이 이동했다면 다시 선택합니다.

과거 검토 문서에 등장했던 외부 음악·영상 서비스 연동은 현재 로컬 미디어 안내와 구분합니다. 특정 스트리밍 서비스의 구독이나 재생 기능을 제공한다고 안내하지 않습니다.

## 화면 보호기

시작 메뉴의 화면 보호기는 태양계 항해·채굴·지구 착륙·태양과 혜성 접근·정거장 도킹 장면을 감상하는 별도 모드입니다. 장면과 화질을 선택하며 보관된 개인 세계를 플레이하거나 덮어쓰는 모드는 아닙니다.
