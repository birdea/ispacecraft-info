# 생존과 몸 상태

상태창의 산소·몸·연료와 AI 패드의 상세 정보를 함께 확인하세요. 도움 기능은 관리를 보조하지만 생존 자원의 필요 자체를 없애지는 않습니다.

## 관리할 자원

| 항목 | 의미와 확인할 것 |
|---|---|
| 산소 | 선내 공기와 우주복 공기를 구분합니다. 밖으로 나가기 전 충전과 귀환 시간을 확인합니다. |
| 물 | 몸 상태를 유지하는 자원입니다. 산소 생산에 사용하는 물과 마실 물의 여유를 함께 봅니다. |
| 식량·활력 | 에너지 상태는 이동과 운반에 영향을 줍니다. |
| 추진 자원 | 우주선 연료와 우주복의 이동 자원을 확인합니다. 멈추기 위한 역분사에도 자원이 필요합니다. |
| 전력 | 장치 가동·산소 생산·채굴·수리에 필요한 조건을 확인합니다. |
| 광석 | 운항·생존 자원으로 변환하거나 거래·보관할 수 있습니다. |

산소 생산과 자동 변환은 남은 물·전력·광석과 탱크 여유에 따라 동작합니다. 자동 관리가 켜져 있어도 원료가 없으면 계속 공급할 수 없습니다.

## 몸 상태

충격·부상·탈수·피폭·온도·중력 환경은 몸 상태와 움직임에 영향을 줍니다. 체력이 남아 있어도 느려지거나 위험한 상태가 될 수 있으므로 알림과 상세 수치를 확인하세요.

우주선 밖에서는 우주복이 흡수한 방사선과 신체 피폭을 구분합니다. 항성 방향과 가림 상태도 관련 규칙에 영향을 줍니다. 짧은 외출이라고 산소와 피폭을 생략해서 판단하지 마세요.

## 우주 유영 전에

1. 우주복과 헬멧·공기 상태를 확인합니다.
2. 에어락의 감압·문 상태를 확인하고 밖으로 나갑니다.
3. 손잡기와 안전줄을 활용해 우주선에서 멀어지는 것을 관리합니다.
4. 돌아올 자원과 진입 가능한 문을 남겨 둡니다.

## 위험할 때

AI 패드는 위험 자원과 가능한 대응을 안내합니다. 경고가 뜨면 채굴이나 다음 이동보다 가까운 안전 위치와 필요한 자원 확보를 먼저 판단하세요. 보조 비행의 자동 정지도 역분사를 사용하므로 중력에 맞서 정지한 상태를 오래 유지하면 연료가 줄 수 있습니다.

## 자리를 비웠다가 돌아오면

일반 세계는 복귀할 때 부재 시간에 따른 동면 계산이 적용될 수 있습니다. 브라우저를 닫는 행동을 모든 상태가 그대로 멈추는 일시정지로 생각하지 마세요. 함대전 캠페인과 저장 칸 불러오기는 각 모드의 규칙을 따릅니다.
