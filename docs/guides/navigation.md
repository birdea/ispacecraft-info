# 항법과 궤도 이동

네비게이션에서 목적지와 도착 동작을 정하고, 직접 조종하거나 AI 운항으로 이동합니다. 위치뿐 아니라 상대 속도·남은 연료·접근 조건을 함께 확인해야 합니다.

## 경로를 정하는 순서

1. 지도나 대상 목록에서 천체·정거장·운석을 선택합니다.
2. 대상 정보에서 목적지와 가능한 행동을 확인합니다.
3. 필요하면 경유지를 추가하고 경로를 검토합니다.
4. 도착 예정과 연료·접근 조건을 확인한 뒤 AI 운항을 시작합니다.
5. 이동 중 현재 단계와 대기 이유, 도착 후 가능한 행동을 확인합니다.

목적지 지정은 경로 초안을 정하는 동작이며, 운항 시작과는 구분됩니다. 대상별 가능한 동작은 실행 중인 앱을 기준으로 확인하세요.

| 대상 | 대표적인 도착 동작 |
|---|---|
| 착륙 가능한 행성·운석 | 접근·착륙 |
| 정거장 | 도킹 |
| 항성·착륙할 수 없는 천체 | 안전한 거리로 접근 |
| 혜성 | 나란히 비행 |

## 속도의 기준

표시되는 속도가 태양·행성·다른 대상 중 무엇을 기준으로 하는지 확인하세요. 같은 위치를 지나가더라도 상대 속도가 크면 바로 착륙·도킹할 수 없습니다.

보조 비행과 정지 명령은 필요한 역분사를 사용합니다. 자동 항법도 연료와 추력·장치 정리 조건을 확인하므로, 자동 조종을 무제한 이동으로 생각하지 마세요.

## 실제 태양계의 궤도 전이

지원되는 실제 태양계 항로에서는 궤도 전이를 사용할 수 있습니다. 출발 때 속도를 바꾸고, 엔진을 끈 채 궤도를 따라 이동한 뒤 도착 때 다시 감속하는 방식입니다.

`지금 출발`과 발사 시기를 기다리는 선택은 이동 시간과 연료가 다를 수 있습니다. 이 기능은 경로 조건에 따라 표시되며 모든 모드·경유지에 공통으로 적용되는 기능은 아닙니다.

## 시간과 속도 조절

시간 배속과 목표 속도는 다른 값입니다. 시간을 빨리 진행하면 자원 소비와 세계 변화도 함께 진행할 수 있습니다. 목표 속도를 바꾸면 항로·제동·연료 조건을 다시 고려해야 합니다.

긴 항해에서는 지원되는 배속을 사용할 수 있지만, 접근·위험·운항 단계에 따라 안전 제한이 걸립니다. 네비게이션의 현재 제어와 제한 이유를 확인하세요.

## 항해 중 확인할 것

- 예상 연료와 이착륙 준비 비용은 구분해서 확인합니다.
- AI가 기다리면 밖에 있는 사람·전개 장치·착륙 가능 조건을 확인합니다.
- 궤도 미리보기는 현재 상태의 예측이며 실제 우주 전체의 모든 중력을 계산한 결과는 아닙니다.
