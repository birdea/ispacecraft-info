# 채굴과 자원 변환

광석을 확보하는 방법은 떠 있는 광석 수거, 운석 표면 채굴, 행성의 매장지·물 이용으로 나뉩니다. 대상과 장비 상태에 맞는 동작을 선택하세요.

## 떠 있는 광석

근처 광석에 접근해 채굴 모드를 사용합니다. 장치가 전개되고 대상을 절삭·수거한 뒤 창고로 운반합니다. 손이 닿는 범위와 적재 공간, 전력 등 작업 조건을 확인해야 합니다.

기본 채굴 장비와 업그레이드 장비는 수거 능력과 외형·작업 동작이 다릅니다. 장비 단계는 정거장에서 확인할 수 있습니다.

## 운석에 착륙해 채굴

1. 착륙 가능한 운석을 선택해 표면에 접근합니다.
2. 착륙과 고정이 끝나면 채굴을 시작합니다.
3. 앵커·후드·절삭·회수 등의 작업 단계를 확인합니다.
4. 창고 용량·전력·광상 잔량을 보며 계속할지 결정합니다.
5. 작업을 끄고 장비 회수와 고정 해제를 마친 뒤 이륙합니다.

광상에는 잔량이 있으며 작업하면 줄어듭니다. 채굴 중 바로 출발되지 않는다면 장비 회수 단계를 확인하세요. 이 채굴의 부재 중 생산을 보장하지는 않습니다.

## 행성 매장지와 물

행성에서는 지형과 매장지를 살펴 착륙 지점을 고릅니다. 채굴 호스가 작업 가능한 곳에 있어야 하며, 물을 얻을 때도 실제 물가와 장비 도달 조건을 확인합니다.

큰 행성에서 많이 확보해도 재이륙과 귀환에 필요한 연료가 부족하면 항해가 어려워집니다. 착륙 전 출발 비용까지 고려하세요.

## 확보한 광석의 쓰임

| 쓰임 | 확인할 부분 |
|---|---|
| 연료·생존 자원 확보 | 변환 재료와 효율, 탱크·보관 여유 |
| 수리 | 선체·장비 손상과 필요한 전력·광석 |
| 거래 | 정거장에 가져갈 수 있는 재고 |
| 공유 창고 | 현재 판에서 사용할 양과 보관할 양 |

자동 변환이 켜져 있으면 캔 광석이 곧바로 연료 등에 쓰일 수 있습니다. 작업은 진행되는데 창고 광석이 늘지 않는다면 자원 변환 상태를 확인하세요. 자동 관리가 변환을 유지하는 경우에는 도움 기능 설정도 함께 확인해야 합니다.

작업량·가격·시간은 조정될 수 있으므로 화면의 현재 값과 장비 설명을 기준으로 판단하세요.
