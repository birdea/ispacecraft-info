# 정거장과 공유 창고

개척 정거장은 광석을 거래하고 물자를 보충하며 우주선을 정비하는 거점입니다. 일반 생존의 다음 항해와 캠페인 보상을 연결하는 곳이기도 합니다.

## 접근과 도킹

정거장을 목적지로 정해 도킹하거나 직접 접근해 상대 속도·자세·전개 장치 조건을 맞춥니다. 도킹 중에는 우주선이 연결 장치에 고정되므로 출발하려면 먼저 분리해야 합니다.

도킹이 끝나면 대상 정보·AI 패드 추천·현지 단말기에서 정거장 서비스를 엽니다. 도킹만으로 서비스 창이 항상 자동으로 열리는 것은 아닙니다. 지원되는 도킹 통로와 로비에서는 선내 이동을 이어갈 수 있습니다.

## 서비스

| 서비스 | 내용 |
|---|---|
| 거래 | 광석 판매와 필요한 물자 구매 |
| 정비 | 손상과 보충이 필요한 항목 확인 |
| 업그레이드 | 채굴 장비·연료 탱크·광석 창고 등의 단계 개선 |
| 공유 창고 | 자원·크레딧과 보관 가능한 장비 넣기·꺼내기 |
| 기록 | 항해와 캠페인에서 남은 결과 확인 |

## 공유 창고의 의미

공유 창고는 **같은 기기·브라우저 안에서 여러 세계와 캠페인이 함께 사용하는 보관함**입니다. 회원 계정이나 기기 간 클라우드 창고를 뜻하지 않습니다.

우주선 안 창고와도 다릅니다. 우주선에 들고 있는 재고를 정거장에서 공유 창고로 넣어야 보관됩니다. 새 게임에서 창고 물건을 쓰려면 정거장에 도킹해 꺼냅니다.

## 자원과 장비를 맡길 때

- 창고에 넣어 둔 것은 사망 후에도 남지만, 가지고 있거나 장착한 것은 같은 방식으로 보존되지 않습니다.
- 장비는 떼어서 보관하고 나중에 장착하거나 바꿔 끼울 수 있습니다.
- 용량 장비를 떼려면 적재량을 줄여야 할 수 있습니다. 작업 중인 장비도 먼저 회수해야 합니다.
- 보관함과 우주선 양쪽에 한도가 있습니다. 캠페인 보상도 한도에 따라 모두 들어가지 않을 수 있으므로 결과를 확인하세요.
- 같이 하기 손님은 개인 공유 창고를 방장 세계에 섞어 사용할 수 없습니다.

## 캠페인 보상

함대전 캠페인은 성공적으로 귀환한 결과를 공유 창고 보상으로 정산합니다. 실패한 판에서 얻은 물건이 모두 보관된다고 생각하지 마세요. 각 판의 목표와 결과 화면을 기준으로 확인하세요.

## 오래된 저장본을 불러올 때

공유 창고를 이용한 뒤 그보다 오래된 세계 저장본을 불러오면 창고와 재고 시점이 어긋날 수 있습니다. 앱은 확인창이나 재고 정리 안내를 제공할 수 있습니다. 실행 전에 해당 안내를 읽고 필요한 세계 파일을 보관하세요.

공유 창고는 세계 내보내기 파일에 포함되지 않습니다.
