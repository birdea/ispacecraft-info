## 현재 범위에 한계가 있는 항목

- P2P 협동은 모든 자원과 거래를 서버가 관리하는 지속 우주가 아닙니다.
- 공유 창고는 기기 안의 여러 세계·캠페인 사이 보관이며 클라우드 저장이 아닙니다.
- 지구 동식물은 시각적 표현과 일부 행동을 제공하며 실제 지리·전체 생태계를 재현하지 않습니다.
- 얼굴은 사진의 특징을 이용한 캐릭터 생성이며 정밀한 3D 인물 복원을 보장하지 않습니다.
- 실세계 자료와 물리 근사를 이용하지만 전문 항법·천문력·교육 도구의 전체 기능을 제공하지 않습니다.

## 후속 계획

태양계 실사 표현과 후속 카툰 쉐이딩, 지형·광원 고도화, 개별 천체로 이어지는 별, 블랙홀, 실존 위성과 탐사선, 지구 궤도 위성 캠페인은 [공개 로드맵](roadmap.md)에 따로 기록합니다.

## 장기 구상과 미정 사항

지속 온라인 세계·연합·평판·경찰 NPC·버려진 우주선의 장기 보존, 자유 증축과 별도 착륙선, 안드로이드 동료·외계 문명은 [장기 구상](concepts/future-society.md)입니다.

최종 출시 플랫폼, 출시일·가격·판매 방식, 계정·클라우드 저장과 교육용 전용 기능은 확정해 안내하지 않습니다. 과거 기획에서 언급된 기능을 현재 구현의 보장으로 해석하지 마세요.
