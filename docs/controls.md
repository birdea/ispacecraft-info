# 조작 안내

아래는 기본 키 배치입니다. 업데이트와 사용자 설정에 따라 달라질 수 있으므로, 실행 중인 앱의 `?` 키 지도와 설정의 키 설정을 우선 확인하세요.

## 키보드

| 키 | 선내 이동·우주 유영 | 조종석 |
|---|---|---|
| `W` `A` `S` `D` | 앞·왼쪽·뒤·오른쪽 이동 | 같은 방향으로 분사 |
| `Q` `E` | 왼쪽·오른쪽 회전 | 왼쪽·오른쪽 회전 |
| `I` `K` | 시선 위·아래 | 기수 들기·숙이기 |
| `U` `J` | 점프·앉기, 떠 있을 때 위·아래 이동 | 위·아래 분사 |
| `G` | 상호작용·조종석에 앉기 | 조종석에서 일어나기 |
| `X` | 역분사로 정지 | 역분사로 정지 |
| `T` | 손잡기 | 앞 창 열기·닫기 |
| `H` | 헬멧 열기·닫기 | 태양판 펼치기·접기 |

| 키 | 기능 |
|---|---|
| `B` | 자동 착륙 |
| `V` | 조종 중 시점 변경 |
| `N` | 네비게이터 지도 |
| `M` | 행성 주변 보기 |
| `F` | 조종 중 채굴 모드 |
| `L` | 조종 중 도킹 관련 동작 |
| `Esc` | 메뉴·열린 화면에서 뒤로 |
| `Tab` | 패널 열기·닫기 |
| `C` | 화면 정보 숨기기·보이기 |
| `?` | 키 지도 |

상황에 따라 사용할 수 없는 동작은 화면 안내를 확인하세요. 순항 등 일부 기능은 현재 설정에서 잠겨 있을 수 있습니다.

## 마우스와 지도

- 바닥을 클릭해 이동하고 드래그해 주변을 둘러봅니다.
- 네비게이터에서 대상을 선택해 정보와 가능한 동작을 확인합니다.
- 빈 지점을 눌러 목적지·경유지를 정할 수 있습니다.
- 지도에서 우클릭하면 해당 위치와 대상에 맞는 메뉴를 엽니다.

## 터치

- 왼쪽 스틱으로 이동·가속하고 오른쪽 스틱으로 자세·회전을 조절합니다.
- 위·아래 버튼은 상황에 따라 점프·앉기·사다리 이동·위아래 추진을 수행합니다.
- 행동 버튼의 이름과 안내를 보고 상호작용합니다.
- 지도에서는 길게 눌러 대상과 위치에 맞는 메뉴를 엽니다.

행동 버튼은 매직 버튼 AI 추천을 사용하거나, 설정에서 직접 고르고 순서를 바꿀 수 있습니다.
