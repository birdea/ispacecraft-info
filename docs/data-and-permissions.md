# 데이터와 기기 권한 안내

플레이에 사용되는 데이터와 권한을 설명합니다. 앱의 메인 화면에서 개인정보 안내와 오픈소스 고지도 확인할 수 있습니다. 기능 변경에 따른 최신 고지는 실행 중인 앱을 기준으로 확인하세요.

## 기기에 남는 데이터

진행·설정·닉네임·가이드 진행·공유 창고·캠페인 기록은 브라우저 저장소를 사용합니다. 자동으로 다른 기기와 동기화되지 않습니다.

얼굴 기능은 원본 사진 대신 얼굴 모양 정보와 꾸미기 값을 기기에 남깁니다. 얼굴 삭제와 저장 칸 삭제는 서로 다른 동작입니다. 브라우저의 사이트 데이터 삭제는 여러 종류의 보관 데이터에 영향을 줄 수 있습니다.

## 카메라와 사진 파일

카메라는 초대 QR 읽기와 얼굴 촬영 등에 사용합니다. 얼굴 사진과 QR 영상은 기기 안에서 처리하며 원본을 저장하거나 서버로 보내지 않습니다.

표준 얼굴을 사용하면 얼굴 촬영을 생략할 수 있습니다. 카메라를 허용했는지와 사용 가능한 장치는 브라우저의 사이트 권한에서 확인할 수 있습니다.

## 같이 하기

연결 과정에는 외부 중계 서비스가 사용됩니다. 서비스와 같은 방 참가자에게 IP 주소 등 접속 정보가 전달될 수 있습니다. 닉네임·우주선과 캐릭터 움직임·일반 외모 정보는 같은 방에서 사용됩니다.

내 얼굴 모양 공유는 별도 설정을 직접 켰을 때만 동작하며 원본 사진을 전달하지 않습니다. 공유를 끄면 해당 얼굴 모양의 전송과 참가자 화면 표시를 중단합니다.

## 로컬 미디어와 외부 자료

선택한 음악·영상 파일은 기기 안에서 읽습니다. 폴더 접근 정보와 재생 목록을 브라우저에 남길 수 있지만, 파일 자체를 다른 기기나 서버에 업로드하는 기능은 아닙니다.

앱과 인식 모델·글꼴 등의 자료를 내려받고 일부 악기 소리는 외부 배포 서비스를 이용합니다. 이런 네트워크 요청은 서버 측 접속 정보를 남길 수 있으므로, 기기 내 처리가 곧 모든 네트워크 요청이 없다는 뜻은 아닙니다.

## 화면을 켜 두는 기능

화면 보호기 등의 감상 기능은 지원 브라우저에서 화면 꺼짐을 막는 권한을 사용할 수 있습니다. 실제 동작은 기기와 브라우저 지원에 따라 달라집니다.

## 문제를 공유할 때

공개 Issues에 사진·방 코드·전체 저장 파일을 무조건 올릴 필요는 없습니다. 버전·기기·재현 순서를 먼저 적고 공개하고 싶지 않은 정보는 화면에서 가려 주세요.
