# 항해와 생존의 흐름

이동·자원 확보·귀환은 하나의 항해로 이어집니다. 멀리 가는 것뿐 아니라 돌아올 연료와 산소를 남기는 판단이 중요합니다.

## 기본 순환

1. **상태 확인**: 산소·몸·연료와 물·식량·전력·선체 상태를 확인합니다.
2. **목표 정하기**: 가까운 광석·운석·행성·정거장을 살펴보고 경로와 도착 동작을 정합니다.
3. **이동하기**: 직접 조종하거나 AI 항법을 사용합니다. 자동 운항 중에도 필요한 연료와 접근 조건을 확인합니다.
4. **자원 확보**: 떠 있는 광석을 채굴하거나 표면에 착륙해 매장지를 이용합니다.
5. **사용과 보관**: 자원을 생존과 운항에 쓰고, 남은 광석은 정거장에서 거래하거나 공유 창고에 보관합니다.
6. **다음 항해 준비**: 선체를 수리하고 장비·용량을 보완한 뒤 다음 목표를 정합니다.

## 매번 달라지는 선택

| 선택 | 함께 고려할 것 |
|---|---|
| 더 채굴할까, 돌아갈까 | 남은 광상·창고 용량·귀환 연료·산소 |
| 광석을 변환할까, 팔까 | 당장 필요한 자원과 정거장까지의 거리 |
| 착륙할까, 가까이서 관측할까 | 중력·대기·지형·추력·이착륙 준비 비용 |
| 바로 출발할까, 궤도 전이를 기다릴까 | 지원되는 항로에서 시간과 연료의 차이 |
| 장비를 달고 나갈까, 맡길까 | 항해 능력과 사망 시 잃는 장비 |

## 실패와 다음 출발

산소 고갈·신체 상태 악화·충돌·선체 파괴는 항해를 끝낼 수 있습니다. 일반 생존에서는 다시 출발해 다음 항해를 이어가고, 캠페인은 해당 판의 성공·실패와 결과 정산을 따릅니다.

장착한 장비와 소지한 자원, 공유 창고에 넣어 둔 자원은 같은 방식으로 보존되지 않습니다. [정거장과 공유 창고](guides/stations-and-vault.md), [저장과 데이터](saving-and-data.md)를 함께 확인하세요.

버려진 우주선 해체·연합 자원 공유·평판 같은 구상은 현재 순환과 별도의 [장기 계획](concepts/future-society.md)입니다.
