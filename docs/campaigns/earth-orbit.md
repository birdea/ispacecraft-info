# 지구 궤도 위성 캠페인 구상

**계획 단계이며 현재 플레이할 수 있는 캠페인이 아닙니다.** 캠페인 이름·임무·보상·실패 조건은 검토 중이고 출시 일정은 정하지 않았습니다.

지구를 도는 약 1만 6천 개 규모의 인공위성을 표현하는 캠페인을 구상하고 있습니다. 전체 궤도 분포를 바라보는 경험과, 그중 하나를 찾아 가까이 관측하는 경험을 연결하려 합니다.

## 표현 방향

- 먼 거리에서는 많은 위성을 가벼운 점·표식으로 표시합니다.
- 개별 대상을 선택하면 이름·종류·궤도·임무 정보를 확인하고 추적합니다.
- 가까워지거나 확대되면 주요 구조·재질·조명이 드러나는 모델로 전환합니다.
- 표현이 바뀌어도 같은 ID·위치·시각을 유지하고 기기 성능에 맞춰 상세도를 조절합니다.

실제 궤도 분포와 관측을 돕는 표식을 구분하려 합니다. 위성들이 우주선 주변에 밀집한 장식으로만 보이는 표현은 목표로 하지 않습니다.

## 플레이 흐름 후보

1. 지구와 전체 위성 분포를 살펴봅니다.
2. 지정된 위성을 이름·ID·궤도로 찾습니다.
3. 추적하고 접근해 거리·상대 속도·관측 시간 조건을 맞춥니다.
4. 남은 연료와 공기를 고려해 다음 관측 또는 귀환을 선택합니다.
5. 관측한 대상과 이동 기록을 결과로 확인합니다.

많은 위성이 배경을 이루되, 실제 임무는 그중 소수의 대상을 중심으로 구성하는 방향입니다.

## 임무 후보

| 임무 | 내용 |
|---|---|
| 궤도 조사 | 서로 다른 고도와 경사각의 위성을 찾아 관측 |
| 군집 추적 | 같은 위성군의 특정 대상을 놓치지 않고 추적 |
| 근접 관측 | 접근해 상대 속도를 줄이고 관측 조건 유지 |
| 궤도 교차 운항 | 다른 궤도면으로 이동하며 근접 예상과 경로 확인 |

위성 수리·회수·폐기와 파편 연쇄 충돌은 첫 범위로 확정하지 않았습니다.

## 위성 수와 궤도 자료

약 1만 6천 개는 규모 목표입니다. 실제 등장 수는 자료를 가져온 시각, 활동 여부와 공개 궤도 자료 유무에 따라 정합니다. 활동 위성·작동 종료 위성·로켓 동체·파편을 구분하고, 표시 중인 수와 전체 목록의 수도 구분할 계획입니다.

NASA Eyes의 표현·추적 흐름을 참고하고, 대규모 지구 위성 목록과 궤도 자료는 CelesTrak 등의 공급처를 검토합니다. 자료가 없는 위성에 임의 위치를 붙이지 않고, 궤도 자료의 기준 시각과 유효 기간을 함께 다룹니다.

판마다 기준 데이터와 시각을 고정해 다시 플레이할 수 있도록 하고, 배속·시간 이동에도 위성과 궤적이 같은 시각을 가리키는 방식을 검토합니다.
