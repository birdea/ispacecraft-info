# 용어 안내

| 용어 | 이 프로젝트에서의 의미 |
|---|---|
| 성계 | 항성을 중심으로 천체가 구성된 세계 단위 |
| 실제·가상 우주 | 태양계 시작 시 거리·속도와 적용되는 궤도 조건을 구분하는 설정 |
| 선내·우주 유영 | 우주선 내부 이동과 우주선 밖에서의 활동 |
| 에어락 | 선내와 외부 사이에서 압력·문을 전환하는 구획 |
| 헬멧·바이저 | 우주복의 머리 보호와 개폐 상태에 관련된 장치 |
| 몸 상태 | 체력·활력·탈수·피폭·온도 등 이동과 생존에 영향을 주는 상태 |
| 피폭 | 우주복 흡수와 신체 방사선 상태에 관련된 값 |
| 선체 내구도 | 우주선 외벽의 손상 상태. 전자기 방어막과는 다름 |
| 광석·태양 광석 | 자원 변환·거래에 사용하는 물자. 태양 광석의 기원은 허구의 세계관 설정 |
| 우주선 창고 | 현재 우주선에 적재한 자원 보관 공간 |
| 공유 창고 | 같은 기기·브라우저의 여러 세계와 캠페인이 함께 쓰는 정거장 보관함 |
| 크레딧 | 거래·보상에 사용하는 앱 안 화폐 |
| AI 항법 | 목적지·경로에 따라 우주선 운항을 돕는 기능 |
| 보조 비행 | 조종 입력을 놓았을 때 역분사 정지를 돕는 설정 |
| 자동 관리 | 일부 헬멧·안전줄·자원 관리를 보조하는 설정 |
| 매직 버튼 | 상황에 맞는 행동을 표시하거나 사용자가 구성하는 버튼 모음 |
| 영향권 | 궤도와 상대 속도 계산에서 기준이 되는 천체 영역 |
| 궤도 전이 | 출발 분사·떠가기·도착 분사로 이어지는 지원 항로의 이동 방식 |
| 시간 배속 | 세계의 시간 진행을 빠르게 하는 제어. 목표 속도와 구분 |
| 시드 | 같은 조건의 세계·천체·지형을 생성하는 데 사용하는 값 |
| 상세도 | 거리·화면 크기·품질에 따라 조절하는 모델·재질 등의 세밀함 |
| 도킹·연합 | 도킹은 연결 동작, 연합은 장기 구상의 상호 합의 관계 |
